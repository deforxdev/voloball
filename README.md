# VOLOBALL

Приватний репозиторій проєкту волейбольної гри на Godot.

## Гілка `ios` — адаптація для iPhone

Це мобільна гілка. Робоча Windows-версія зберігається окремо в гілці `windows`.

Для iPhone додано горизонтальний екран, сенсорні стіки руху й прицілу, кнопки удару/стрибка/пасу/блоку/нирка/подачі, спавн м'яча, спринт, стійку, камеру, меню та зміну видимого рівня сили. Графіка починає з легкого профілю, 75% 3D-роздільності й обмеження 60 FPS. Управління враховує безпечну область екрана.

GitHub Actions у `.github/workflows/ios.yml` використовує macOS і Xcode, збирає iPhone ARM64 та пакує **непідписаний IPA для SideStore**. Apple ID, пароль, сертифікат і provisioning profile не потрібні для цієї збірки; SideStore виконує підписання на етапі встановлення.

Після успішної збірки: GitHub → Actions → iPhone IPA for SideStore → успішний запуск → артефакт `VOLOBALL-iPhone-SideStore`. Розпакувати завантажений ZIP та відкрити IPA у SideStore. Сертифікати й термін підпису керуються SideStore.

Запуск сенсорної версії у Windows для перевірки: Godot із аргументами `-- --mobile-preview`. Окремий тест: `test_mobile_controls.tscn` із тими самими аргументами. Перевірка на фізичному iPhone залишається окремим кроком.

## Базова Windows-версія

Ця гілка зберігає поточний робочий Windows-проєкт, включно з виправленнями керування м'ячем. Це базова версія для подальшого перенесення гри на мобільні платформи.

### Запуск

1. Відкрити `project.godot` у Godot 4.7.1 для Windows.
2. Натиснути F5 для запуску гри.
3. Поточний рендерер — Forward+; налаштування збережені в `project.godot`.

Проєкт відновлено з білда. Частина вихідних ресурсів відсутня, тому `.godot/imported/`, UID-мапи, `.assets/` і `.autoconverted/` навмисно збережені в Git. Не видаляти ці каталоги з цієї базової версії. Локальний стан редактора та кеш шейдерів виключені.

### Поточна поведінка м'яча

- G у практиці створює вільний м'яч на 2,6 м над персонажем.
- V повертає м'яч у руки для подачі; наступне V запускає подачу.
- Видима сила 1–3 запускає підкидання з мінігрою, вищі рівні — автоматичну подачу. Правило враховує налаштований максимум шкали, зокрема 9 і 10.
- Підкидання підвищене; повторна подача після падіння м'яча знову запускає мінігру.

### Перевірка

```powershell
& 'E:\Godot_v4.7.1-stable_win64.exe' --headless --path . --scene res://test_ball_controls.tscn
```

Тест перевіряє спавн, повторні подачі та видимі рівні сили для максимумів шкали від 3 до 16. Перевірки проходили на Godot 4.7.1; мобільні збірки ще не перевірені.

## Наступний етап: Android та iPhone

- Android: адаптувати гру для телефона, додати сенсорне керування та отримати інсталяційний APK.
- iPhone: адаптувати гру для iOS і підготувати IPA для встановлення через SideStore.
- Перевірити продуктивність, мобільний рендерер, розкладку інтерфейсу й залежності від настільних платформ.
- Для експорту та збирання iOS потрібні macOS і Xcode. Мобільні пакети в цій гілці ще не створені.

Джерела: [експорт Godot для iOS](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_ios.html), [SideStore FAQ](https://docs.sidestore.io/docs/faq).
